# 웰러 구현·검증

- 4☆ / Zombie / HP 160. 억누른저주 `RorB*`는 공통 코스트 파서·지불 UI에서 `R*` 또는 `B*`로 처리한다.
- 점액막은 HP 보호막이 있을 때 공통 피해 경감·대상 선택·행동 승인에 적용한다. 범위 기술은 유지하고 기술 사용·후퇴는 막는다. 특성이 정지하면 점액막도 정지한다.
- 그레이브업은 공통 사망 처리 전에 발동한다. 인스턴스에 사용 완료를 저장하고, 언데드 4턴과 선형 감소(차례마다 -40) HP 보호막 160을 부여한다. 회복은 고정값이 아니라 보호막이 자연 감소로 실제 줄어든 양만큼만 일어나며, 받은 피해로 줄어든 보호막은 환급하지 않는다(`healOnDecay`). 발동한 자기 차례에 언데드 지속 턴을 즉시 차감하지 않는다.
- 언데드는 공통 상태이상이다. Zombie 태그면 HP 0에서 생존하고, 그 외는 회복이 피해로 전환된다. 분배 회복·초과 회복 처리도 반전을 반영한다. HP 0에서 언데드가 종료·치료되면 공통 사망 판정을 다시 실행한다.
- 저주는 웰러의 다음 자기 차례 시작을 1·2·3턴째로 계산한다. 예약은 다른 지연 기술과 같은 공통 경로의 슬롯 예약이라 대상 UID를 저장하지 않는다. 슬롯에 교체 캐릭터가 들어오면 그 캐릭터에게 이어서 적용되고, 슬롯이 비면 불발한다. 마지막 피해는 당시의 전체 공격력 감소량×4를 기본값으로 공통 공격 피해 경로에 전달한다. 감소분을 제거할 때 증가분은 유지한다.
- 그레이브다운은 엄격한 현재 HP 비교 후 HP를 0으로 만든다. 공통 사망 판정을 사용하므로 그레이브업·Zombie 언데드는 정상 반응한다.
- 저주 봉인·폭발, 그레이브다운 묘비, 그레이브업 재기 연출은 기존 온라인 VFX 저널을 사용한다. Zombie 언데드 오오라는 CSS 애니메이션이며, 스냅샷으로 DOM이 교체돼도 공통 시각 시계를 이용해 입자 진행을 유지한다.

검증: 정적 검사 통과, 단위 검사 7개, 기존 전투·온라인 브라우저 검사 18개, 웰러 검사 17개, 실제 릴레이의 모바일 클라이언트 회귀 검사 23개 통과. 새 웰러 검사에는 양쪽의 저주 연출 1회 표시, 재전송 중복 방지, 언데드 스냅샷 복구가 포함된다. 기존 54개 카드의 정의와 행동 486개 상황, 일반전 1,296턴·보스전 64턴 비교도 통과했다.

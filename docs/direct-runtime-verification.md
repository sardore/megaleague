# 직접 호출 구조 검증

기준 버전: `a31c68b0cd3dea2c6e1223ee2f5001346e625f91`.

## 변경한 실행 경로

- 번호 기반 `policySlots`와 enter/leave/transform 실행기를 삭제했다. 합법 행동은 기술별 대안을 합치고 공통 제약을 적용한다. 효과는 종류별 직접 분기로 처리한다. 화면 갱신 순서는 `src/ui/payment.js`에 명시했다.
- 보스가 공통 함수의 이전 구현으로 되돌아가는 전달 래퍼 14개와 `bossRulesReady` 초기화 우회를 삭제했다. 공통 함수가 필요한 보스 규칙을 직접 호출한다. 처치 보상은 공통 사망 처리의 생존→사망 전이에서 한 번만 발생한다.
- 타이머는 `src/runtime/timers.js`에서 한 번 생성하고 소비자가 직접 import한다. 설정 객체의 별칭과 화면 초기화에서의 중복 등록을 제거했다. 이전 두 등록은 서로 다른 구현이 아니라 같은 객체였다.
- 시계 회전 오버레이와 시각 포화 서비스도 모듈의 직접 의존성으로 연결했다. 게임 시작 안내는 입력 잠금·온라인·화면 서비스 초기화 후에 시작한다.
- 정적 검사는 삭제한 레지스트리, 서비스 별칭, `this`를 전달하는 call/apply 래퍼, 전역 쓰기 및 프로토타입 패치의 재도입을 거부한다.

## 기능 비교

`node tools/check-feature-parity.js /path/to/a31c68b-checkout`을 Chromium에서 실행했다.

| 비교 | 결과 |
|---|---|
| 카드 정의 | 54개 일치 |
| 에너지·상태·플러스스타 조합의 행동 대안 | 486개 상황에서 유효한 행동의 순서·대상·코스트 일치 |
| 같은 유효 명령을 사용하는 고정 시드 일반전 | 1,296턴 상태·난수 결과 일치 |
| 솔로·온라인 협동 보스전 | 64턴 상태·공용 시계·난수 결과 일치 |
| 시뮬레이션 예외 | 양쪽 모두 없음 |

이전 일반 기술 재추가 경로가 루비의 HP 조건을 건너뛰어, HP 150에서 파이어스톰을 노출하는 경우 6개를 확인했다. 새 경로는 카드의 선언된 HP 조건을 적용하며 플러스스타의 명시적 조건 해제는 유지한다. 비교 검사는 이 잘못된 기존 행동만 공통 메타데이터로 걸러내며, 새 버전에 조건 위반 행동이 없음을 별도로 단언한다. 전투 비교는 양쪽에서 같은 유효 명령을 선택하며 AI 선택 결과가 동일하다는 검사는 아니다. 매 턴 상태를 깊게 복사해 후속 턴의 변경이 과거 증거를 바꾸지 않게 했다.

## 회귀 검사

- `npm run validate:static`: 통과. 84개 소스 모듈.
- `npm test`: 7개 통과. 단일 타이머를 통한 세션 종료 시 예약 취소 포함.
- `node tools/check-combat-online.js`: 18개 통과. 보스 카드·공용 시계·화면, 시간 방벽과 붉은 하이퍼클락 연출, 처치 보상 중복 방지 포함. 공방 능력치 162개 조합과 온라인 상대 연출 재전달 검사도 유지했다.

빌드된 JavaScript는 855,352바이트로 기준본 864,420바이트보다 9,068바이트 작다. 실행 시 외부 JavaScript 라이브러리는 사용하지 않는다. 브라우저 회귀 검사는 실제 Android 기기의 OS 중단 동작 전체를 보증하지 않는다.
